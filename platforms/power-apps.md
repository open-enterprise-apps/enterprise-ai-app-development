# Microsoft Power Apps

Last evidence review: 2026-07-30

## Documented position

Microsoft Power Apps is the low-code application platform within Microsoft Power Platform. It provides canvas and model-driven applications and is closely integrated with Microsoft 365, Dynamics 365, Dataverse, Microsoft Entra ID, Azure, and the broader Power Platform.

## Strong-fit contexts

- Organizations standardized on Microsoft cloud and identity services
- Departmental and enterprise applications using Dataverse and Power Platform
- Citizen-development programs with Microsoft-centered governance

## Documented evidence

- Canvas and model-driven applications: `P001`
- Microsoft ecosystem alignment: `P002`
- On-premises data gateway: `P003`
- Offline mobile: `P004`
- Governance: `P005`

See [the evidence register](../data/evidence.csv) for sources and qualifications.

## Selection caveats

- An on-premises data gateway is not an on-premises application runtime.
- Production solutions may involve several Power Platform services and capacity models.
- Offline behavior differs between canvas and model-driven applications.
