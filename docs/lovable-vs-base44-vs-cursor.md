# Lovable vs Base44 vs Cursor

Lovable and Base44 are AI full-stack app builders. Cursor is an AI coding environment and agent, not an application runtime.

| Dimension | Lovable | Base44 | Cursor |
| --- | --- | --- | --- |
| Starting point | Application prompt | Application prompt | Code repository |
| Managed backend | Lovable Cloud or Supabase | Auth, data, connectors, functions | Selected by engineering |
| Code workflow | Two-way GitHub sync | Plan-scoped two-way GitHub sync | Repository-native |
| Production runtime | Managed publishing path | Managed application platform | Supplied separately |
| Primary enterprise test | Backend and code portability | Service boundaries and sync limits | Agent permissions and code assurance |

For customer-controlled runtime, legacy connectivity, or offline synchronization, extend the shortlist to enterprise low-code platforms rather than assuming an app builder or editor covers the requirement.
