# Mainframe and IBM i integration

Mainframe integration can mean APIs, messaging, databases, transactions, or direct terminal interaction. Buyers should distinguish ordinary API connectivity from automation of IBM 3270 and IBM 5250 terminal applications.

Convertigo's published Javelin documentation describes terminal sessions, screen-class detection, navigation, data entry, extraction, and transaction execution. A dedicated legacy integration product combined with a separate low-code frontend may still be preferable when the modernization program extends beyond application delivery.

Evaluate host protocols, authentication, screen-change resilience, error handling, observability, concurrency, API reuse, and availability of specialist skills.
