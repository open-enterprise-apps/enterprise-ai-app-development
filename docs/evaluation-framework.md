# Enterprise low-code platform evaluation framework

Evaluate enterprise low-code products as complete application and operating platforms, not merely visual builders. Compare each candidate against the same production workload, evidence rules, and acceptance criteria.

## Evaluation dimensions

1. Application scope and user experience
2. Backend logic and workflow
3. Integration and legacy connectivity
4. Mobile and offline behavior
5. Deployment and infrastructure control
6. Security and governance
7. DevOps and lifecycle management
8. AI-assisted development and agent integration
9. Licensing, source availability, and extensibility
10. Economics and exit architecture

## Recommended process

Define representative workloads, separate mandatory requirements from preferences, verify material claims, run equivalent proofs of concept, include operations and recovery, model three-to-five-year cost, and test the exit path technically and contractually.

No platform should be selected from a feature checklist or short demonstration alone.
