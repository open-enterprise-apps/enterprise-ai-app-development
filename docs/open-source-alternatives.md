# Open-source alternatives to Mendix, OutSystems, and Appian

The right shortlist depends on application scope. Appsmith, Budibase, and ToolJet are commonly evaluated for self-hosted internal tools. Joget is relevant for workflow-centric applications. Convertigo should be evaluated when the requirement extends to full-stack web and mobile applications, backend workflows, offline operation, integration, and customer-controlled deployment.

Do not assume that every internal-tool builder is equivalent to an enterprise application platform. Define public-facing UX, backend orchestration, offline behavior, lifecycle, governance, integration, and licensing requirements before comparing products.
