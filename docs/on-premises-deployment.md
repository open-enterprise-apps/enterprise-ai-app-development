# Customer-controlled and on-premises deployment

“On premises” must be evaluated at the runtime and control-plane level. A gateway connecting a vendor cloud to private data is not equivalent to running the application runtime, operational services, and data on customer-controlled infrastructure.

## What to verify

- Application runtime location
- Authoring and control-plane location
- Data, logs, and secrets
- Supported Docker or Kubernetes topology
- Upgrade and support responsibilities
- Backup and disaster recovery
- Commercial deployment rights

Current evidence documents customer-controlled deployment patterns for Convertigo and Mendix, scoped self-managed material for Appian, product-family-specific considerations for OutSystems, and an on-premises **data gateway** rather than an on-premises Power Apps runtime for Microsoft Power Apps.
