# Offline mobile applications

Several enterprise low-code platforms document offline mobile patterns, but the architectures and constraints differ. A production evaluation should test local persistence, synchronization, conflicts, attachments, authentication expiry, encryption, recovery, and realistic data volumes.

The current dataset contains scoped evidence for Convertigo FullSync, Mendix offline-first native mobile, OutSystems 11 offline mobile, Appian Offline Mobile, and Power Apps canvas and model-driven mobile applications.

Use the same data, identity policy, network failures, conflict scenarios, and acceptance criteria for every proof of concept.
